# Road Issues Detection using Deep Learning

This project detects road issues using a CNN-based deep learning model.
The model was trained using TensorFlow and Keras with image augmentation.

## Tools & Technologies
- Python
- TensorFlow / Keras
- NumPy, Matplotlib
- Google Colab

## Accuracy
- Achieved ~85% accuracy on validation data

## Use Case
Helps identify road damages for smart city and traffic management systems.
